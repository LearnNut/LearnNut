# LearnNut

LearnNut turns videos, documents, audio, and text into knowledge a learner can explain and remember.

## Current checkpoint

The real Expo project is initialized with:

- Expo SDK 57
- React Native and TypeScript
- Expo Router
- LearnNut brand tokens and final icon
- A working welcome-to-home navigation flow
- Accessible safe-area layout and touch targets

Backend accounts, source processing, AI, subscriptions, and production analytics are intentionally not connected yet.

## Run on a phone

1. Install Node.js 22.13 or newer.
2. Install Expo Go on the phone.
3. Open Terminal in this folder.
4. Run `npm install`.
5. Run `npm start`.
6. Scan the QR code with the phone while both devices use the same Wi-Fi.

## Verify the project

- TypeScript: `npx tsc --noEmit`
- Expo health check: `npx expo-doctor`
